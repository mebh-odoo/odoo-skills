# Skills

- **[grill-me](./grill-me/SKILL.md)** - Generic grilling session for stress-testing plans and designs one question at a time.
- **[grill-with-docs](./grill-with-docs/SKILL.md)** - Grilling session that challenges plans against domain language, `CONTEXT.md`, and ADRs.
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)** - Find deepening opportunities that improve testability and AI-navigability.
- **[odoo](./odoo/SKILL.md)** - Odoo addon development, exploration, debugging, architecture review, and manifest/docs sync.
- **[odoo-17.0](./odoo-17.0/SKILL.md)** - Odoo 17 reference guides for actions, controllers, data, decorators, fields, manifests, migrations, mixins, models, OWL, performance, reports, security, testing, transactions, translations, and views.
- **[odoo-18.0](./odoo-18.0/SKILL.md)** - Odoo 18 reference guides for actions, controllers, data, decorators, fields, manifests, migrations, mixins, models, OWL, performance, reports, security, testing, transactions, translations, and views.
- **[odoo-19.0](./odoo-19.0/SKILL.md)** - Odoo 19 reference guides for actions, controllers, data, decorators, fields, manifests, migrations, mixins, models, OWL, performance, reports, security, testing, transactions, translations, and views.
- **[odoo-20.0](./odoo-20.0/SKILL.md)** - Odoo 20 reference guides for actions, controllers, data, decorators, fields, manifests, migrations, mixins, models, OWL, performance, reports, security, testing, transactions, translations, and views.
- **[odoo-code-review](./odoo-code-review/SKILL.md)** - Odoo review workflow for correctness, security, performance, migrations, tests, manifests, and official coding guidelines.
- **[odoo-code-tracer](./odoo-code-tracer/SKILL.md)** - Execution-flow tracing for controllers, buttons, cron jobs, model methods, overrides, computes, onchanges, constraints, side effects, and security checks.
- **[odoo-grill-me](./odoo-grill-me/SKILL.md)** - Odoo-specific grilling session for stress-testing addon plans, security, data models, UI flows, OWL changes, migrations, and verification strategy.
- **[odoo-guidelines](./odoo-guidelines/SKILL.md)** - Official Odoo house rules for addon code: module structure, manifest, Python/ORM, fields, controllers, XML views and data, QWeb reports, access rights, performance, and tests.
- **[odoo-idea-gates](./odoo-idea-gates/SKILL.md)** - Odoo-aware idea validation for deciding whether a module, addon, app, or product should exist before implementation.
- **[odoo-migration](./odoo-migration/SKILL.md)** - End-to-end OCA module migration workflow for porting addons between Odoo major versions.
- **[odoo-owl](./odoo-owl/SKILL.md)** - Odoo OWL frontend engineering, including components, templates, reactivity, hooks, plugins, debugging, and migration.
- **[odoo-report-design](./odoo-report-design/SKILL.md)** - QWeb HTML/PDF report layout, print CSS, paper formats, assets, pagination, localization, and review.
- **[odoo-report-migration](./odoo-report-migration/SKILL.md)** - Report migration between Odoo versions with baseline rendering and visual-regression checks.
- **[odoo-review](./odoo-review/SKILL.md)** - Official Odoo code review that checks each changed file against `odoo-guidelines`, `odoo-web-guidelines`, and `odoo-security`.
- **[odoo-security](./odoo-security/SKILL.md)** - Official Odoo security audit: access control, `sudo`, SQL/domain/eval injection, XSS, untrusted public methods and RPC.
- **[odoo-website](./odoo-website/SKILL.md)** - Odoo website and portal engineering for QWeb, public and portal controllers, website assets, and frontend integration.
- **[odoo-web-guidelines](./odoo-web-guidelines/SKILL.md)** - Official Odoo house rules for JavaScript, Owl templates, and SCSS in `static/src/` and `static/tests/`.
- **[odoo-web-security](./odoo-web-security/SKILL.md)** - Security guidance for Odoo public and portal routes, browser-facing data, HTML output, tokens, uploads, and trust boundaries.
- **[odoo-web-testing](./odoo-web-testing/SKILL.md)** - HTTP, browser, tour, JavaScript, asset, and access-matrix testing for Odoo web flows.
- **[odoo-test-writer](./odoo-test-writer/SKILL.md)** - Odoo test creation with TransactionCase, SingleTransactionCase, HttpCase, AccountTestInvoicingCommon, Form helper, tags, mocked external APIs, access tests, workflow tests, and coverage patterns.
- **[zoom-out](./zoom-out/SKILL.md)** - Higher-level map of unfamiliar code and how relevant modules and callers fit together.

The four official skills (`odoo-guidelines`, `odoo-web-guidelines`, `odoo-security`, `odoo-review`) are copied unchanged from [odoo/odoo `skills/`](https://github.com/odoo/odoo/tree/20.0/skills) (branch 20.0, commit a22b3e7) and reference each other, so keep them together.
